# personal-learning-loop

个人学习闭环：一个 Obsidian 学习库 + 一个 AI 学习教练 Skill。

## 结构

| 路径 | 用途 |
| --- | --- |
| `index.md` | 学习库总览 |
| `topics/` | 实际课程，每门课一个目录 |
| `inbox/` | 尚未分类的资料、外部 AI 原始结果 |
| `attachments/` | PDF、图片、音视频和练习文件 |
| `templates/` | 课程结构与配套模板 |
| `skills/personal-learning-loop/` | 学习教练 Skill：诊断 → 教学 → 评估 → 复习 → 收口 |

## 用法

用 Obsidian 打开本目录作为仓库。Skill 说明见 `skills/personal-learning-loop/SKILL.md`。

笔记内容为个人学习记录。
