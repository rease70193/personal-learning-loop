# 收口与周期调整

## 一次学习结束

用户说“结束/收口”，或明确完成一个单元时再汇总；普通单轮提问不触发全套日记。中途重要进度可简短保存，不能因此宣布用户今天已结束。

默认包含三项：

1. **证据：** 今天实际做出了什么；哪些只是讲过或提示后完成。
2. **下一步：** 最多三项，每项有完成标准和估计时间，合计适合下次预算。
3. **待验证：** 当前卡点或原因假设；没有就省略。

有错误时追加题目、用户表现、反馈和关联能力；有计划偏差时追加事实→原因假设→一次可验证调整；用户希望保留遗憾/教练观察时再展开。没有错误无需造错题，没有证据无需造观察。

下次第一件事按相关缺口、到期复习和目标紧迫性选择；无错题时可推进新能力。用户已经要求轻量记录，就不要重复输出存盘全文。

写入规则见 [存储协议](storage.md)。成功写入后只简报位置和变化；无法写时输出一个可粘贴续接块，包含主题、已验证能力、未完任务、下次行动与未保存状态。

## 周复盘或用户指定的周期

读取该主题周期内会话摘要与相关能力卡，按需追查证据。不跨主题混算，不因为缺一天日记就判作学习失败。

可计算的数据：

- **计划完成率：** 周期内标记完成的行动数 / 当时有效的已承诺行动数。取消或替换项另列，不能靠事后删除失败项抬高完成率。没有清晰分母则记“无法可靠计算”。
- **延迟保持表现：** 不同日期、无提示的复习通过数 / 有效无提示复习次数。提示后练习不混入；样本很少时列原始次数，不作强结论。
- **重复缺口：** 同一能力的同类可核实错误在不同尝试中出现几次；同题立即重答不重复计数。不要只按宽泛“概念不清”合并不同能力。
- **能力变化：** 哪些从未验证/学习中变为独立通过或保持通过，链接证据，不只报总数。

## 分开判断时间与知识

| 证据 | 调整方向 |
|---|---|
| 时间不足，但独立表现良好 | 减量或改时间安排，保持内容层级 |
| 目标所需前置反复未通过 | 只补相关前置，缩小当前任务 |
| 当前能力独立通过且延迟检验良好 | 增加难度或迁移范围，是否加量看预算 |
| 记录缺失、题目有争议或证据混合 | 暂不定性，用一次短测或短周期实验补证据 |

允许“减量＋补一个前置”同时存在，不强迫三选一。百分比可以提示调查，不能独自决定退级。已完成 90% 但某个关键能力仍错，就针对该能力修补。

最终给：主要证据、下周期最多两个调整、一个验证方式。将原因写为假设，允许用户纠正；从“没学完”不能推导“懒”。有用户明确目标变化再改档案，否则只调整计划。
