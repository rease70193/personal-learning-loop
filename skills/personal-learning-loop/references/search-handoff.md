# 给其他 AI 的灵活检索提示词

仅在用户选择外部 AI 检索、明确要求检索提示词，或需要补齐外部结果时读取。这里用于生成本次交接文本，不是要求用户手动填表，也不授权自动向外部服务发送内容。

## 先选本次检索形态

根据已有目标和资料缺口选择，不强迫用户先选择模板：

| 当前情况 | 提示词重点 |
|---|---|
| 零基础、不知先看什么 | 一份低门槛主材料＋一个小练习，说明必要前置 |
| 卡在某个概念或操作 | 围绕具体卡点找短解释、实例与常见误区，不给完整课程 |
| 已懂概念，缺实践 | 可运行项目/练习、环境要求、验收标准；答案与题目分开，避免提前泄露 |
| 需要系统课程 | 课程范围、顺序、总投入和阶段产出，按期限筛选，不默认只找短文 |
| 已有教材或视频 | 只补它没覆盖的缺口，避免同质重复推荐 |
| 要比较多个说法或来源 | 一手依据、适用条件、发布时间和分歧，不以热度代替可靠性 |

数量随目标调整：局部补缺通常 1–3 个；课程比较可适当增加；用户给数量则遵守，确实找不够不凑数。

## 组装成可直接复制的文本

从档案、会话和已给资料中填入必要内容：

1. **我在学什么、为了做什么。** 使用具体目标，而非“高效学习这个领域”。
2. **我的现状。** 已会什么、当前卡点、已有材料覆盖了什么。只传达检索所需摘要，不整份复制私人日记或无关个人信息。
3. **这次要找什么。** 一个明确检索任务，说明范围外内容和资源数量/可接受少给。
4. **限制与偏好。** 按实际需要添加语言、形式、免费/付费、时间、设备、软件版本、先修要求；未知不要编造。学习预算不总等于资源总时长，系统课程可按每次可学时长拆分。
5. **怎么返回结果。** 最小要求是标题/作者或机构、原始链接、匹配缺口的理由；按场景增加重点章节/可核实时间戳、阅读顺序、练习与验收标准、环境要求或时效信息。
6. **真实性约束。** 要求实际检索，注明未能访问或未核实的内容，不编链接、章节、时间戳、费用；没有联网能力先说明。不能要求其他 AI 保证自己无法证实的事实。

默认用自然语言段落或简短列表，不强制统一字段数、不要求复杂 JSON。简单任务提示词短一些，复杂课程比较才展开。只交付一份最适合的成品，除非用户要求多个版本。

## 可调整骨架（生成时替换为已知内容）

“请实际检索能帮助我完成【具体目标】的资料。我已经能【已有能力】，目前卡在【具体缺口】；现有【材料及覆盖范围】不需要重复推荐。

这次请优先找【资料类型/检索范围】，满足【实际限制】。先给【适量数量】个；不足就说明缺什么，不凑数。

每条给出标题、作者或机构、原始链接、为什么适合我的这个缺口，以及【本场景需要的章节/练习/环境等】。最后建议先用哪一份，以及用完后能独立完成什么。

请打开原始来源核实，无法核实的内容明确标注。不要编造链接、章节、时间戳或价格；如果无法联网，请先说明，不把猜测包装成检索结果。”

这是生成结构，不应原样留空交给用户。用户背景不足但仍想立即拿提示词时，用已知信息生成能执行的简版，最多留下极少数确实无法代填的内容，并指出哪些是假设。

## 交接说明

提示词外只补一句：“把对方的结果原样带回来，我会核实、筛选并接入你的学习库。”不能承诺一定能打开所有平台链接；实际无法核实时按资源协议标注。

用户指定某 AI 时可以称呼它，但不要假设它一定支持联网、视频解析或某个上传入口。用户想先讨论怎么找时先给简短策略，确认选择 B 后再输出完整文本。

## 补检索而非反复重来

结果全是长课程而用户只缺一个操作：追问该操作的短示例与明确章节。只有链接没有匹配说明：围绕现有链接要求补定位。来源失效：要求寻找原作者的有效入口或同等可靠替代。提示词引用必要结果编号即可，不复制整份学习档案。

补充完毕走 [资源接回流程](resources.md)，再按 [存储协议](storage.md) 保存所采用的资料。
